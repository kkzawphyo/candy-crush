Candy Crush Game 

A fun, interactive Candy Crush–style puzzle game built with React.
The game focuses purely on gameplay — no user authentication or accounts required.

🎮 Features
Match-3 puzzle gameplay
Colorful candy grid
Drag & drop interactions
Score tracking
Automatic match detection
No login / no user data stored

🛠️ Tech Stack

React
JavaScript (ES6+)
HTML5
CSS3
